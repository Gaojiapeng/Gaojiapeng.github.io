# Jiapeng Gao — Personal Website

Visitor analytics use [GoatCounter](https://www.goatcounter.com/).
Sign in to the [analytics dashboard](https://aighiehighe.goatcounter.com/) to view traffic.

The home page, publications, gallery, and all three ExoplanetML pages load the
official asynchronous tracker. Each page reports a fixed path, excluding query
parameters and URL fragments. Local previews are excluded by GoatCounter's
`allow_local: false` setting. The old `astrophotography.html` redirect is not
tracked separately; the destination gallery records the visit.

Changes take effect after deployment to GitHub Pages. Browser blocking of the
analytics script can prevent visits from being counted. Integration details:
https://www.goatcounter.com/help/js
