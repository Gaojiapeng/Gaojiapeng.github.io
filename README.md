# Jiapeng Gao — website preview

Open `index.html` to view the AcademicPages website, or `gallery.html` for the Apple-inspired photo gallery. At the homepage’s bottom, keep scrolling downward to pull against resistance, reveal Jiapeng’s Milky Way photograph, and unlock the Gallery. The photograph stays hidden until you pull; pausing or reversing retracts it. The down-arrow cue and upper menu also provide direct Gallery links, including without JavaScript.

This is the generated static site. The editable Jekyll project is in the neighboring `academicpages-source` folder and in `Jiapeng_Gao_AcademicPages_Source.zip`. See that source folder’s README for editing and build instructions.

The homepage’s ExoplanetML introduction links to `projects/exoplanetml/final.html`. The project’s proposal, midterm report, and figures are included, with a return link to the homepage.

The website has not been published. All ten photographs retain dates or years, locations, and “Photographed by Jiapeng Gao” credits. Theme provenance is in UPSTREAM.md and the retained MIT license is in LICENSE.
